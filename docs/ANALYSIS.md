## C. 컬러 · 타이포그래피

**컬러** — 레이어 이름은 Pantone 021C / 127C를 가리키지만, 파일 내 색은 **별색(Separation)이 아니라 CMYK 프로세스 값과 DeviceN(Magenta/Yellow) 그라데이션**으로 정의되어 있다. 별색 지정은 레이어 단위로 인쇄소에 전달되는 구조로 보인다.

| 용도 | 원본 값 | 화면 근사 |
|---|---|---|
| 앞면 배경 (orange_021c) | C0 M70 Y98 K0 | #F37025 |
| 개인정보·로고 텍스트 | K98 | #2A2728 |
| 뒷면 박스 | K100 | #231F20 |
| 뒷면 바이너리 문구 | K70 | – (고정 이미지) |
| 실크 판 표시색 | M100 | #EC008C (**판 표시용, 인쇄색 아님**) |

**서체**

| 서체 | 용도 | 크기 | 자간(Tc) |
|---|---|---|---|
| Gotham Bold | 영문 이름, 영문 소속·직책, 이메일, 연락처 | 7.5pt (이메일 7.8pt) | 소속·직책·이메일 −10, 이름·연락처 0 |
| SUITE Heavy | 국문 이름, 한글 소속 | 7.5pt | 소속 +20, 이름 −5 |
| Pretendard **Black** | 이메일의 `@` 한 글자 | 7.8pt | 0 |
| SUITE Heavy (아웃라인) | 회사 주소 — 한글·숫자·영문 모두 | 7.5pt | −10 |

`@`는 PDF에 `PretendardVariable-Regular`로 기록되지만, 임베드된 글리프의 외곽선·면적·폭이 Pretendard Black(900)과 일치 → 가변 폰트 굵기를 Black으로 적용한 것으로 판단. 재현 검증(914dpi 겹침): '@' 잉크 영역 위치·크기 0.01pt 이내 일치, 글리프 IoU 0.96.

주소는 아웃라인이라 서체 정보가 없어 글리프 크기로 역산: 모든 글자의 높이·폭 비율이 SUITE Heavy 7.5pt와 일치(숫자·영문 포함), 글자 간 간격으로 자간 −10 확인. 구분 기호 `•`는 문자가 아니라 대각선 2.268pt 마름모 도형.

한 행 안에서 한글은 SUITE, 영문·숫자는 Gotham으로 섞어 씀 (예: `교육기획 ` + `3 GROUP`). 영문은 모두 대문자, 이메일은 소문자, 전화번호는 `010.1234.1234` 마침표 구분. 모두 좌측 정렬.

## D. 후가공 · 인쇄 사양

- 후가공 레이어: **`실크` 1종, 뒷면에만 존재**. 적용 영역 = L자 프레임 전체(도련 포함) + 주황 강조 문구 3구절.
- 앞면에는 후가공 없음.
- 실크의 실제 효과(UV, 형압, 질감 등)는 파일에서 확인할 수 없다 → 미리보기에서 질감을 임의로 만들지 않고 **영역만** 표시.

## 웹 재현 방식

| 요소 | 방식 | 이유 |
|---|---|---|
| 앞면 고정 (배경·로고·워드마크) | 원본에서 추출한 **벡터 SVG** | 플랫 색상이라 무손실 |
| 회사 주소 | SVG 텍스트 (`spec.ts`의 `ADDRESS`) | 주소 변경 시 한 곳만 수정 |
| 앞면 개인정보 | **라이브 SVG 텍스트** (원본 좌표·서체·자간) | 실시간 반영 |
| 뒷면 인쇄 레이어 | 원본 600dpi 렌더 이미지 | DeviceN 그라데이션 + 소프트 마스크가 SVG 변환 시 저해상도로 손실됨 |
| 뒷면 실크 | 벡터 SVG, 별도 그룹 | 인쇄 그래픽과 분리 관리 |
| 인쇄용 템플릿 | `print-templates/*.pdf` — 원본 페이지를 레이어 유지한 채 추출 (앞면은 텍스트만 제거) | 향후 PDF 생성 시 원본 벡터·색공간 그대로 사용 |

## 정합성 검증

검증용으로만 원본 PDF 임베드 Gotham 서브셋을 테스트 브라우저에 주입해, 아트보드 2·4·6과 동일 데이터를 300dpi로 겹쳐 비교 (`fidelity-overlay-artboard6.png`: 검정=일치, 빨강=원본만, 청록=재현만).

- 이름·소속·직책·이메일: 위치·크기 일치
- 차이 ① 전화번호 등에서 Illustrator가 적용한 Gotham 커닝(최대 0.4pt) — 실제 Gotham이 설치된 PC에서는 브라우저도 서체 커닝을 적용
- 차이 ② 3행 구성의 행간: 원본 아트보드마다 9.1/9.3/9.4pt로 다름 → 9.3pt 단일값 사용 (최대 0.2pt ≈ 0.07mm)
